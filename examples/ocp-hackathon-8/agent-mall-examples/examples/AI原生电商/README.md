# Nexa AI 原生电商

一个面向笔记本电脑的 AI 原生电商 Demo：商家录入普通商品资料后，商品理解 Agent 自动生成结构化画像、语义文本和检索向量；用户只需描述需求，选购 Agent 会执行关键词、向量和条件约束混合检索，并返回可直接展示的商品卡片。

## 核心功能

- 商家控制台：经营概览、商品录入、库存调整和订单状态管理。
- 商品理解 Agent：标准化笔记本规格，提取用途与优势标签，生成 24 维本地向量。
- 用户端：自然语言需求理解、预算/内存/重量约束提取、混合检索和推荐解释。
- 订单闭环：用户确认创建沙盒订单，商家端实时查看并更新状态。
- 本地 SQLite：同时保存业务数据、AI 画像、语义文本和向量，无云服务依赖。

## 技术设计

```text
商家原始商品 -> 商品理解 Agent -> AI 画像 + 语义文本 + 向量 -> SQLite
用户自然语言 -> 需求理解 Agent -> 关键词 + 向量 + 约束检索 -> 商品卡片 -> 沙盒订单
```

数据库选择 SQLite，原因是 Demo 无需安装数据库服务、数据文件可直接携带，并且结构化字段、JSON AI 画像、向量和订单能保存在同一个本地事务数据库中。向量相似度由应用层计算，适合当前少量演示商品；生产环境应换用支持向量索引的 PostgreSQL + pgvector 或专用向量库。

## 运行步骤

要求 Node.js 22.5 或更高版本，本机需包含 `node:sqlite`。

```powershell
cd "C:\Users\29082\Desktop\agent-mall-examples\examples\AI原生电商"
node scripts/generate-assets.mjs
node --disable-warning=ExperimentalWarning server.mjs
```

无需安装 npm 依赖，也不需要 API Key。启动后访问：

- 用户端：<http://127.0.0.1:4173>
- 商家端：<http://127.0.0.1:4173/merchant>

首次启动会自动创建 `data/commerce.sqlite`，并写入 6 款虚拟笔记本和 1 条演示订单。

## 推荐演示流程

1. 打开商家端，在“录入商品”中输入一款笔记本，点击“交给 Agent 处理并发布”。
2. 展示 Agent 自动生成的场景标签、语义文本和向量预览。
3. 回到用户端输入：`预算 6000 元以内，想要轻薄、续航长，平时通勤办公`。
4. 展示 Agent 提取的条件、关键词分数、向量语义分数和推荐理由。
5. 对首选商品创建演示订单，再回商家端更新订单状态和库存。

## 限制与外部依赖

- 商品、库存和订单均为本地虚拟数据。
- 向量由针对笔记本场景的本地特征模型生成，不调用在线大模型。
- Demo 不执行真实付款、发货或外部订单操作。
- 无第三方代码、图片或数据；商品图由仓库内脚本生成。
