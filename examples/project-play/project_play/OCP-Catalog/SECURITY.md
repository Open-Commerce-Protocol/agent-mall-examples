# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through the repository's **Security → Advisories → Report a vulnerability** feature.

Do not disclose unresolved security issues through public GitHub issues, discussions, or pull requests.

Please include, where available:

* A description of the issue
* The affected component or version
* Steps to reproduce the issue
* The potential security impact

We aim to acknowledge security reports within 14 calendar days. Resolution and public disclosure timelines will be determined case by case based on severity, complexity, and available maintainer resources.

The project currently evaluates reports against the current `main` branch. No long-term support commitment is currently provided.
